Anmelden zum Bearbeiten

Zum Speichern braucht die Seite einen GitHub-Zugangsschlüssel, der nur für dieses Projekt gilt. Ansehen und Ausprobieren geht auch ohne.

  1. In GitHub einen neuen „Fine-grained token“ anlegen ↗.
  2. Name z. B. „Zeitleiste Redaktion“, Ablaufdatum nach Wunsch.
  3. Repository access: „Only select repositories“ → AustrianHistoryMap.
  4. Permissions → Repository permissions → Contents: „Read and write“.
  5. „Generate token“ und den Schlüssel (beginnt mit github_pat_) hier einfügen.

Änderungen speichern und veröffentlichen

    Nach dem Speichern wird die Zeitleiste automatisch neu gebaut und hochgeladen; das dauert etwa 2–3 Minuten.
